# Chaturthi & Chulanghan Restaurant app

Daily-use app for orders, billing, sales, stock, credit, staff and attendance.
Open it on a phone and use **Add to Home screen**.

- Data is stored in Google Firebase (project `chaturthi-chulanghan`); people sign in with Google.
- Owners give access in the app: **Menu → App access**.
- Settings for the Firebase connection are in `config.js`.
